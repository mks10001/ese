# ese 语言规范 v2.0

> ese —— 一门用对称括号书写的极简全栈语言。
> 一套符号同时描述页面、数据与逻辑，写完就是网站。

---

## 一、设计哲学

1. **对称即语法**：每个符号都是一对括号，左右呼应，像浮雕一样框住内容。看见开头就知道结尾。
2. **块状思维**：程序不是一行行代码，而是一个个嵌套的「框」。框里放框，层层组装。
3. **中文友好**：关键字支持中文（打印、放入、3次），写程序像写中文排版稿。
4. **前后端同形**：页面布局和后端逻辑用同一套括号风格描述，不切换心智。

**文件约定**：主程序文件固定命名 `ese.bd`，模块文件自由命名但扩展名一律 `.bd`。

## 二、符号总表（v2.0 完整版）

| 符号 | 名称 | 用途 | 层 |
|------|------|------|----|
| `[+ +]` | 浮雕框 | 页面容器，包住一段界面内容 | 前端 |
| `[- -]` | 文字块 | 显示一段文字 | 前端 |
| `[* *]` | 媒体块 | 显示图片或视频 | 前端 |
| `[= =]` | 输入框 | 接收用户输入 | 前端 |
| `[( )]` | 按钮 | 纯按钮（可配合路由跳转） | 前端 |
| `[> <]` | 行为按钮 | 点击后触发逻辑的按钮 | 前端 |
| `[/ /]` | 路由 | 页面路径声明或跳转目标 | 前端 |
| `[---]` | 分割线 | 上下内容之间画一条线 | 前端 |
| `[> >]` | 执行块 | 触发/执行一段逻辑 | 逻辑 |
| `[? ?]` | 分支块 | 条件判断 | 逻辑 |
| `[~ ~]` | 循环块 | 重复执行 | 逻辑 |
| `[!!]` | 结束/注释 | 语句收尾；`[! ... !]` 为注释 | 通用 |
| `[# #]` | 数据抽屉 | 定义变量 / 存数据 | 数据 |
| `[$ $]` | 计算器 | 算术与数值运算 | 数据 |
| `[q p]` | 查询块 | 向数据库提问 | 后端 |
| `[b d]` | 后端块 | 服务器端逻辑（b=backend） | 后端 |
| `[u n]` | 用户块 | 用户身份、登录、权限 | 后端 |
| `[@ @]` | 网络块 | 请求外部接口 / 获取网络数据 | 后端 |
| `[w m]` | 排版块 | 控制宽度、布局、样式（w=width, m=measure） | 前端 |

> **v2.0 变更说明**
> - 原草案中 `[> >]` 与 `[> <]` 职责重叠，已拆分：`[> >]` 只做执行，`[> <]` 只做可点击按钮。
> - `[@ @]]`（草案笔误多一个右括号）已修正为 `[@ @]`。
> - 未定义的 `[b d] [u n] [w m] [q p]` 已全部补齐定义。这四组正好是镜像字母对（b/d、u/n、w/m、q/p），延续「对称」哲学。

## 三、基础语法规则

### 规则 1：一切皆嵌套

框可以套框，内层写完必须有对应右括号：

```
[+
  [- 外层文字 -]
  [+
    [- 内层文字 -]
  +]
+]
```

### 规则 2：语句用 `[!!]` 收尾

一个独立语句（文字、按钮、赋值……）写完后加 `[!!]` 表示结束。容器框（`[+ +]`、`[? ?]` 等）闭合时自带结束，不需要 `[!!]`。

```
[- 你好 -] [!!]
```

### 规则 3：注释

```
[! 这里是注释，不参与执行 !]
```

### 规则 4：分割线

```
[---]
```

## 四、符号详解

### 4.1 前端层

**浮雕框 `[+ +]`** —— 页面容器

```
[+
  打印 "欢迎来到我的网站"
+]
```

**文字块 `[- -]`**

```
[- 欢迎来到我的网站 -] [!!]
```

**媒体块 `[* *]`** —— 支持图片与视频

```
[* 头像.png *] [!!]
```

**输入框 `[= =]`** —— 用户输入，可绑定变量名

```
[= 名字 =] [!!]
```

**按钮 `[( )]` 与 路由 `[/ /]`** —— 纯按钮，跳转到某页面：

```
[( 去首页 )] [/ /home /] [!!]
```

**行为按钮 `[> <]`** —— 点击后执行逻辑：

```
[> 立即进入 <] [!!]
```

**排版块 `[w m]`** —— 控制布局与样式：

```
[w
  宽 = 600
  居中
m] [!!]
```

### 4.2 逻辑层

**执行块 `[> >]`** —— 触发一段逻辑：

```
[>
  打印 "你点了我！"
>] [!!]
```

**分支块 `[? ?]`**：

```
[? 名字 == "张三"
  [- 欢迎老板！ -]
?]
```

支持否则分支：

```
[? 名字 == "张三"
  [- 欢迎老板！ -]
  [?? 
    [- 你是谁？ -]
  ??]
?]
```

**循环块 `[~ ~]`**：

```
[~ 3次
  [- 循环中 -]
~]
```

### 4.3 数据层

**数据抽屉 `[# #]`** —— 定义变量：

```
[# 名字 = "张三" #] [!!]
[# 计数 = 0 #] [!!]
```

**计算器 `[$ $]`** —— 数值运算：

```
[$ 计数 = 计数 + 1 $] [!!]
[$ 总价 = 单价 * 数量 $] [!!]
```

### 4.4 后端层

**后端块 `[b d]`** —— 服务器端逻辑，写在 `.bd` 文件内，由 `ese.bd` 声明引用：

```
[b
  [# 用户列表 = [] #] [!!]
d] [!!]
```

**用户块 `[u n]`** —— 身份、登录、权限：

```
[u
  登录 名字, 密码
  [? 登录成功
    跳转 /home
  ?]
n] [!!]
```

**查询块 `[q p]`** —— 向数据库提问：

```
[q
  取出 用户 where 名字 == 名字
p] [!!]
```

**网络块 `[@ @]`** —— 请求外部接口：

```
[@ 获取用户数据 @] [!!]
[@ "https://api.example.com/data" 存入 外部数据 @] [!!]
```

## 五、程序结构

一个完整的 ese 项目：

```
我的项目/
  ese.bd        ← 主程序（入口，固定名字）
  其他模块.bd    ← 可选的功能模块
```

`ese.bd` 的标准骨架：

```
[ese.bd
  [+ 
    [- 欢迎来到 ese 的世界！ -] [!!]
    [- 这是一个支持前后端的对称符号语言。 -] [!!]
  +] [!!]
] [!!]
```

## 六、完整示例：登录页面

```
[! ese.bd —— 完整登录示例 !]

[# 名字 = "" #] [!!]
[# 密码 = "" #] [!!]

[+
  [- 欢迎回来，请登录 -] [!!]
  [---] [!!]
  [- 请输入名字 -] [!!]
  [= 名字 =] [!!]
  [- 请输入密码 -] [!!]
  [= 密码 =] [!!]
  [> 登录 <] [!!]
+] [!!]

[>
  [q
    取出 用户 where 名字 == 名字
  p] [!!]
  [? 登录成功
    [u 跳转 /home n] [!!]
    [??
      [- 名字或密码不对，再试一次 -] [!!]
    ??]
  ?]
>] [!!]
```
