# ese 语言规范 v2.2

> ese —— 一门用对称括号书写的极简全栈语言。
> 一套符号同时描述页面、数据与逻辑，写完就是网站。

**v2.2 核心变更**：补齐数据结构（列表/字典/遍历）· 裁决三处词法歧义 · 定义运行时错误处理策略 · 新增路由系统 · 新增状态管理 · 新增 ese-ui 标准组件库 · 新增测试体系 · 新增 SSR 编译模型。**符号表维持 17 对冻结不变**，所有新能力通过关键字、内置函数与编译目标实现。

## 二、词法歧义裁决（v2.2 破坏性修订）

### 2.1 媒体块：文件名禁含 `*`

`*` 是媒体块定界符。规则：**遇到第二个 `*` 即视为块结束**，文件名中的 `*` 一律非法，ese check 报错。

```
[* 头像.png *]        [! 合法 !]
[* a*b.png *]         [! 非法：文件名含 * !]
```

### 2.2 路径：禁止前导斜杠

`[/` 与 `/]` 是定界符，**括号内的路径不得以 `/` 开头**（消除 `//` 歧义）。URL 前导斜杠由编译器自动补全。

```
[/ home /]            [! 合法：路径为 home !]
[/ /home /]           [! 非法：路径以 / 开头 !]
跳转 home             [! 跳转同样不带前导斜杠 !]
```

> 本条同时修订 v2.0/v2.1 中 `[( 去首页 )] [/ /home /]` 的写法，统一为 `[/ home /]`。

### 2.3 插值：仅允许出现在文字块与字符串内

`{变量}` 只在 `[- -]` 文字块和字符串字面量内被解析为插值；在**值位置**（`[$ $]`、条件、属性值、字典字面量）`{ }` 表示字典字面量（见第三节）；其他位置一律为普通字符。

```
[- 你好，{名字} -]         [! 插值：合法 !]
[# 用户 = { "名字" : "张三" } #]   [! 值位置：字典字面量 !]
```

## 三、数据结构（v2.2 新增）

### 3.1 列表与字典

```
[# 名单 = ["张三", "李四", "王五"] #]
[# 用户 = { "名字" : "张三", "等级" : 3 } #]
```

- 列表字面量：`[ 元素, 元素, … ]`。
- 字典字面量：`{ "键" : 值, … }`，**仅允许出现在值位置**（键用引号字符串，键名无需遵循标识符规则）。

### 3.2 访问与操作

**字典用点语法**，列表索引用内置函数：

```
[$ 名字 = 用户.名字 $]              [! 字典取值：用户.名字 !]
[$ 第一 = 取第(名单, 1) $]          [! 列表取项：序号从 1 开始 !]
[$ 个数 = 长度(名单) $]             [! 列表/字典长度 !]
[$ 加入(名单, "赵六") $]            [! 尾部追加 !]
```

**内置数据函数表**（第一批）：

| 函数 | 签名 | 行为 |
|------|------|------|
| `取第` | 取第(列表, 序号) | 取第 n 项，序号从 1 开始；越界触发运行时错误 |
| `长度` | 长度(列表或字典) | 元素个数 |
| `加入` | 加入(列表, 值) | 尾部追加，无返回值 |
| `包含` | 包含(列表, 值) | 返回 是/否 |
| `键列表` | 键列表(字典) | 返回全部键组成的列表 |

**函数调用语法**：`函数名(参数, …)` 仅允许出现在**表达式位置**（`[$ $]`、条件、插值、属性值内），永不与按钮 `[( )]` 冲突——按钮只出现在语句位置，由文法区分。

### 3.3 遍历循环

```
[! 遍历列表 !]
[~ 遍历 名单 为 项
  [- {项} -]
~]

[! 遍历字典：项.键 与 项.值 !]
[~ 遍历 用户 为 项
  [- {项.键} = {项.值} -]
~]
```

遍历时修改被遍历的集合为未定义行为，ese check 给出警告。

## 四、错误处理（v2.2 新增）

采用**两级策略**：

### 4.1 属性缺省兜底（宽容级）

- 组件调用缺少属性：若组件定义了默认值则用默认值；否则取**空串**（数值语境取 0）。
- ese check 静态扫描时对缺属性调用给出**警告**（非错误）。

```
[+ 组件 欢迎卡
  属性 名字 = "游客"          [! 默认值语法：属性名 = 默认值 !]
  [- 你好，{名字} -]
+]
[< 欢迎卡 >]                   [! 使用默认值 "游客"，不报错 !]
```

### 4.2 计算错误即停（严格级）

以下情况**立即终止渲染/执行**，报错信息包含**文件名、行号、符号与原因**：

- 除以零、类型不匹配的运算；
- `取第` 越界、访问字典不存在的键；
- 调用未定义的函数或组件；
- 跳转到未声明的页面路径。

```
[! 报错示例格式 !]
错误：ese.bd 第 12 行 —— 除以零（[$ 一半 = 总数 / 0 $]）
```

> 设计理由：低代码用户需要「页面能出来」（宽容），但算错了必须立刻看见（严格）。静默吞错或复杂捕获语法都会伤害目标用户。

## 五、路由（v2.2 新增）

### 5.1 页面声明

用 `[/ 页面 路径 … /]` 声明一个页面，体内为该页面的内容。`ese.bd` 中可声明多个页面。

```
[ese.bd
  [/ 页面 home
    [+ 居中
      [- 这是首页 -]
    +]
  /]

  [/ 页面 用户/{id}
    [- 用户编号是 {id} -]
  /]
]
```

- 路径可含参数段：`用户/{id}`，页面体内用 `{id}` 引用。
- 未声明在任何页面内的顶层内容，编译为 `index` 页面的组成部分。
- 一个 `.bd` 模块文件中不允许出现页面声明（页面只属于 `ese.bd`），模块只提供组件与函数。

### 5.2 跳转与链接

```
[( 去用户页 )] 跳转 用户/3         [! 按钮跳转（携带参数） !]
```

`跳转` 为内置函数，参数为路径字符串，支持 `{变量}` 引用当前作用域值：`跳转 用户/{id}`。

## 六、状态管理（v2.2 新增）

### 6.1 三级状态

`[# 变量 = 值 #]` 声明位置决定状态层级：

| 声明位置 | 层级 | 生命周期 | 可见范围 |
|----------|------|----------|----------|
| `ese.bd` 顶层（页面外） | **全局状态** | 应用整个运行期 | 所有页面与组件（只读，需通过函数修改） |
| `[/ 页面 … /]` 体内 | **页面状态** | 页面打开期间 | 该页面及其中组件 |
| 组件体内 | **组件状态** | 组件存活期间 | 仅该组件 |

### 6.2 响应式规则

- **任何状态被赋值（`[$ x = … $]`）时，所有引用它的界面部分自动更新**——声明式响应，无手动刷新。
- 数据流单向：**属性向下传，事件向上抛**。组件修改外部状态的唯一途径是执行块回调（`调用` 传入的命名逻辑块）。
- 全局状态的修改只允许发生在全局执行块中；页面/组件直接赋值全局状态被 ese check 拒绝（防止跨层隐式改写）。

```
[! 全局执行块（ese.bd 顶层） !]
[> 全局 :
  [$ 计数 = 计数 + 1 $]        [! 合法：修改全局状态 !]
>]
```

### 6.3 SSR 下的状态语义

- 全局状态：**每个请求独立初始化**（请求隔离，不跨用户共享）。
- 页面状态：服务端渲染初值，客户端接管。
- 组件状态：仅存在于客户端水合之后。

## 七、UI 组件库：ese-ui 标准库（v2.2 新增）

### 7.1 组件调用的子内容（插槽）

v2.2 扩展组件调用：`[< >]` 内部可以携带内容块，在组件体内通过内置语句 `渲染 内容` 输出到指定位置。

```
[! 定义：带插槽的组件 !]
[+ 组件 卡片框
  属性 标题 = ""
  [+ 边框
    [? 标题 != ""
      [- {标题} -]
    ?]
    渲染 内容
  +]
+]

[! 调用：携带子内容 !]
[< 卡片框 标题="公告"
  [- 这是卡片正文 -]
>]
```

### 7.2 标准库第一批（编译器内置，无需引入）

| 组件 | 用法 | 说明 |
|------|------|------|
| `卡片` | `[< 卡片 标题="…" > 子内容 >]` | 带标题的圆角卡片容器 |
| `列表` | `[< 列表 数据=名单 > [- {项} -] >]` | 遍历渲染数据，子内容中可用 `{项}` 与 `{序号}` |
| `导航栏` | `[< 导航栏 项目=[["首页","home"],["关于","about"]] >]` | 顶部导航，每项为 [文字, 路径] |

> 后续批次（表单组、标签页、弹窗等）按同样机制扩充；第三方组件库通过 `引入` 使用，与标准库调用方式完全一致。

## 八、测试（v2.2 新增）

### 8.1 测试文件

- 扩展名约定：`xxx.test.bd`。
- 测试文件中顶层每条 `断言` 语句为一个用例；执行块中也可包含断言（用于测交互逻辑）。

```
[! 相加.test.bd !]
断言 "加法正确" 相加(1, 2) == 3
断言 "零处理" 相加(0, 0) == 0

[> 测试组件 :
  [# 结果 = 渲染文本(欢迎卡, { "名字" : "测试" }) #]
  断言 "组件输出包含名字" 包含(结果, "测试") == 是
>]
```

### 8.2 断言与运行

- 内置函数：`断言(名称, 实际表达式)`，表达式中使用 `==` / `!=` / `>` 等，成立返回 `是`，不成立返回 `否`；`断言` 收到 `否` 即记为失败。
- 命令：`ese test` 递归执行所有 `*.test.bd`，输出每个用例的通过/失败与行号；失败不影响其他用例继续。

## 九、SSR 与编译模型（v2.2 新增）

**SSR 是编译目标，不是语言特性——不引入任何新语法。**

| 命令 | 模式 | 行为 |
|------|------|------|
| `ese build` | 静态生成（默认） | 所有页面预渲染为独立 HTML + 一份小体积交互 JS；纯展示页面零 JS |
| `ese serve` | 服务端渲染 | 页面按请求实时渲染为 HTML；交互部分水合（hydration）后由客户端接管 |

规则：

1. 页面声明式部分（浮雕框/文字/媒体/组件）在服务端渲染为完整 HTML——**首屏无白屏**。
2. 执行块、输入绑定、组件状态编译为按页拆分的 JS，仅在含有交互的页面加载。
3. 全局状态在 SSR 模式下每请求独立（见 6.3）。
4. 纯静态站点用 `ese build` 产物可直接部署到任意静态托管。

## 十、文法增补（EBNF 增量，v2.2）

```ebnf
(* ===== v2.2 增补 ===== *)

(* 路由页面声明 *)
route-page    = "[" , "/" , "页面" , path , LF , { item , LF } , "]" ;
path          = path-segment , { "/" , path-segment } ;        (* 禁止前导斜杠 *)
path-segment  = identifier | "{" , identifier , "}" ;

(* 遍历循环 *)
loop          = ... | "[" , "~" , "遍历" , identifier , "为" , identifier , LF ,
                { item , LF } , "]" ;

(* 带子内容的组件调用（插槽） *)
component-call = "[" , "<" , identifier , prop-pass* , LF ,
                 { item , LF } , ">" , "]" ;
children-render = "渲染" , "内容" ;

(* 属性默认值 *)
attr-line     = "属性" , identifier , [ "=" , value ] , { "," ,
                identifier , [ "=" , value ] } ;

(* 函数调用（仅表达式位置） *)
func-call     = identifier , "(" , [ value , { "," , value } ] , ")" ;

(* 值扩展 *)
value         = ... | list-literal | dict-literal | func-call | "是" | "否" ;
list-literal  = "[" , [ value , { "," , value } ] , "]" ;     (* 仅值位置 *)
dict-literal  = "{" , dict-pair , { "," , dict-pair } , "}" ;  (* 仅值位置 *)
dict-pair     = string , ":" , value ;
member-access = identifier , "." , identifier ;

(* 语句扩展 *)
jump          = "跳转" , path ;
assert        = "断言" , string , expression ;
```

**词法裁决（已并入文法）**：`media` 的 filename 终端不再接受 `*`；`path` 不以 `/` 开头；`interpolation` 只能出现在 `text-body` 与 `string` 内。

## 十一、完整示例：多页面计数站（v2.2 全特性）

```
[ese.bd
  [! ===== 全局状态 ===== !]
  [# 访问语 = "欢迎来到 ese 站点" #]

  [> 全局 :
    [$ 访问语 = "欢迎回来！" $]
  >]

  [! ===== 组件 ===== !]
  [+ 组件 计数器
    属性 起始 = 0
    [# 当前 = 起始 $]           [! 组件状态 !]
    [+ 居中
      [- 当前计数：{当前} -]
      [> 加一 <] 调用 加一
      [> 归零 <] 调用 归零
    +]
    [> 加一 :
      [$ 当前 = 当前 + 1 $]     [! 赋值即自动刷新界面 !]
    >]
    [> 归零 :
      [$ 当前 = 0 $]
    >]
  +]

  [! ===== 页面 ===== !]
  [/ 页面 home
    [< 导航栏 项目=[["首页","home"],["关于","about"]] >]
    [- {访问语} -]
    [< 计数器 起始=10 >]
    [< 卡片 标题="名单"
      [~ 遍历 名单 为 项
        [- {序号}. {项} -]
      ~]
    >]
    [( 去关于页 )] 跳转 about
  /]

  [/ 页面 about
    [- 关于本站：ese v2.2 构建 -]
    [( 回首页 )] 跳转 home
  /]
]
```

部署：`ese build` 生成 `home.html`、`about.html` 与交互脚本；`ese serve` 则按请求渲染。
