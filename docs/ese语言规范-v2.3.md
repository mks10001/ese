# ese 语言规范 v2.3（增量）

> ese —— 一门用对称括号书写的极简全栈语言。
> 一套符号同时描述页面、数据与逻辑，写完就是网站。

**本文档为 v2.2 的增量规范**：未提及的一切规则沿用 v2.2。v2.3 只做两件事——**① 定义运算符优先级；② 引入 `[ee]` / `[zz]` 双语模式**。

---

## 一、变更总览

| 类别 | 变更 | 性质 |
|------|------|------|
| 运算符 | 定义完整优先级与结合性表；新增逻辑运算符 `并且/或者/非`（英文 `and/or/not`） | 破坏性修订（v2.1–v2.2 为严格左结合） |
| 双语模式 | `[ee]` 英文模式 / `[zz]` 中文模式，按文件声明关键字语言 | 新增（编译指令，不占用符号表） |

## 二、运算符优先级（v2.3 新增）

### 2.1 完整运算符表

v2.3 起，表达式运算采用**标准数学优先级**，取代 v2.1–v2.2 的严格左结合。优先级从高到低：

| 优先级 | 运算符 | 中文写法 | 英文写法 | 结合性 | 说明 |
|--------|--------|----------|----------|--------|------|
| 1（最高） | `( )` | — | — | — | 括号，永远最高 |
| 2 | 函数调用 | `取第( )` 等 | `take( )` 等 | 左 | 见 2.3 |
| 3 | 一元非 | `非 x` | `not x` | 右 | 逻辑取反 |
| 4 | 一元负号 | `-x` | `-x` | 右 | 数值取反 |
| 5 | 乘除 | `*` `/` | `*` `/` | 左 | |
| 6 | 加减 | `+` `-` | `+` `-` | 左 | |
| 7 | 比较 | `==` `!=` `>` `<` `>=` `<=` | 同左 | 左 | 返回 是/否 |
| 8 | 逻辑与 | `并且` | `and` | 左 | |
| 9（最低） | 逻辑或 | `或者` | `or` | 左 | |

**示例**：

```
[$ 结果 = 1 + 2 * 3 $]                    [! 7，不再是 v2.2 的 9 !]
[$ 判定 = 名字 == "张三" 并且 等级 >= 3 $]
[? 非 已登录 或者 计数 > 10
  [- 请先登录 -]
?]
```

### 2.2 类型规则（配合优先级）

- `+` 两端**必须同为数值或同为字符串**：字符串相加为拼接；数值与字符串混加为**运行时错误**（即停，报行号）——不做隐式转换。
- 比较运算两端必须同类型；`==` 对列表/字典做深度相等比较。
- 需要转换时用内置函数：`转数字(x)` / `转文字(x)`（中英 `toNumber(x)` / `toText(x)`）。

### 2.3 内置函数表（补全）

此前散落的内置函数在此统一收录（括号内为英文模式写法）：

| 函数 | 签名 | 说明 |
|------|------|------|
| `打印` (`print`) | 打印(x) | 输出到控制台/构建日志 |
| `跳转` (`goto`) | 跳转(路径) | 页面跳转 |
| `取第` (`take`) | 取第(列表, 序号) | 取第 n 项，从 1 起 |
| `长度` (`len`) | 长度(列表或字典) | 元素个数 |
| `加入` (`push`) | 加入(列表, 值) | 尾部追加 |
| `包含` (`contains`) | 包含(列表或字典, 值) | 是否包含 |
| `键列表` (`keys`) | 键列表(字典) | 全部键的列表 |
| `转数字` (`toNumber`) | 转数字(x) | 文字转数值，失败即停 |
| `转文字` (`toText`) | 转文字(x) | 任意值转文字 |
| `断言` (`assert`) | 断言(名称, 表达式) | 测试断言 |
| `渲染` (`render`) | 渲染 内容 (`render children`) | 插槽输出（语句形式） |

## 三、双语模式：`[ee]` / `[zz]`（v2.3 新增）

### 3.1 基本规则

- `[ee]`：**英文模式**——之后的关键字、内置函数、逻辑运算符用英文写法。
- `[zz]`：**中文模式**——之后用中文写法（默认模式，可省略）。
- **按文件声明**：写在文件第一行（或任意顶层位置，作用到文件结尾或下一个模式标记）。
- **括号符号两种模式完全相同**（`[+ +]`、`[- -]` 等不随语言变化）——模式只切换「词」，不切换「框」。
- 自定义变量名与组件名**任何模式下都可用中文或英文**，模式不影响标识符。

```
[! 中文模式（默认，可省略 [zz]） !]
[zz]
[+ 组件 欢迎卡
  属性 名字 = "游客"
  [- 你好，{名字} -]
+]
[< 欢迎卡 名字="张三" >]
```

```
[ee]
[! English mode !]
[+ component WelcomeCard
  prop name = "guest"
  [- Hello, {name} -]
+]
[< WelcomeCard name="Tom" >]
```

### 3.2 完整关键字对照表（v2.3 官方）

| 中文（[zz]） | 英文（[ee]） | 用途 |
|--------------|--------------|------|
| 组件 | component | 组件定义 |
| 属性 | prop | 组件形式参数 |
| 调用 | call | 事件绑定 |
| 渲染 内容 | render children | 插槽输出 |
| 页面 | page | 路由页面声明 |
| 跳转 | goto | 页面跳转 |
| 引入 … 的 … | import … from … | 模块引用 |
| 全局 | global | 全局执行块 |
| 遍历 … 为 … | for … as … | 遍历循环 |
| 次 | times | 计数循环 |
| 并且 | and | 逻辑与 |
| 或者 | or | 逻辑或 |
| 非 | not | 逻辑非 |
| 是 / 否 | true / false | 布尔值 |
| 断言 | assert | 测试断言 |
| 取第 / 长度 / 加入 / 包含 / 键列表 | take / len / push / contains / keys | 数据函数 |
| 转数字 / 转文字 | toNumber / toText | 类型转换 |
| 打印 | print | 输出 |

### 3.3 模式与模块

- 模式**只在文件内有效**：`ese.bd` 可以是中文模式，`utils.bd` 可以是英文模式，互相 `引入` 时关键字各自按本文件模式解析——**组件名是跨语言的**（`引入 "./card.bd" 的 WelcomeCard` 在中文文件里照样调用，因为标识符不随模式变化）。
- ese check 对**同一文件内多次切换模式**给出风格警告（建议一文件一模式）。
- `[ee]` / `[zz]` 是**编译指令**（pragma），不是数据容器：不进入符号表、不可嵌套内容、必须独占一行。

### 3.4 文法增补

```ebnf
(* v2.3 增补 *)
pragma        = "[" , ("ee" | "zz") , "]" , LF ;
(* 关键字终端按当前模式查表解析，文法结构不变：
   例如 branch 在 [zz] 下 condition 用 中文比较语义，
   在 [ee] 下 "and"/"or"/"not"/"true"/"false" 等价替换中文终端 *)
logic-op      = "并且" | "或者" | "and" | "or" ;   (* 按模式二选一 *)
unary-not     = "非" | "not" ;
boolean       = "是" | "否" | "true" | "false" ;
```

## 四、完整示例：同一逻辑的两种语言

```
[zz]
[# 名单 = ["张三", "李四"] #]

[/ 页面 home
  [? 长度(名单) > 0 并且 包含(名单, "张三")
    [- 名单里有张三，共 {长度(名单)} 人 -]
    [??
      [- 名单是空的 -]
    ??]
  ?]
  [( 去英文页 )] 跳转 en
/]
```

```
[ee]
[! same file logic, English mode !]
[# list = ["Tom", "Jerry"] #]

[/ page home
  [? len(list) > 0 and contains(list, "Tom")
    [- Tom is in the list, {len(list)} people total -]
    [??
      [- list is empty -]
    ??]
  ?]
  [( to Chinese page )] goto zh
/]
```
