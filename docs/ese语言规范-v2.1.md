# ese 语言规范 v2.1

> ese —— 一门用对称括号书写的极简全栈语言。
> 一套符号同时描述页面、数据与逻辑，写完就是网站。

**v2.1 核心变更**：取消 `[!!]` 语句收尾（换行即结束）· 新增形式化文法（EBNF）与作用域规则 · 新增组件定义与 `[< >]` 调用语法 · 后端四符号降级为预留区 · 明确工具链优先路线。

---

## 一、设计哲学

1. **对称即语法**：每个符号都是一对括号，左右呼应，看见开头就知道结尾。
2. **块状思维**：程序是一个个嵌套的「框」，框里放框，层层组装。
3. **中文友好**：关键字支持中文（打印、取出、3次）。
4. **前后端同形**：页面布局和后端逻辑用同一套括号风格描述。
5. **换行即结束**（v2.1 新增）：一行一个语句，换行就是句号。不为收尾付税。

**文件约定**：主程序文件固定命名 `ese.bd`，模块文件自由命名但扩展名一律 `.bd`。

## 二、符号总表

### 2.1 正式符号（v2.1 已定义、可使用）

| 符号 | 名称 | 用途 | 层 |
|------|------|------|----|
| `[+ +]` | 浮雕框 | 页面容器，包住一段界面内容 | 前端 |
| `[- -]` | 文字块 | 显示一段文字 | 前端 |
| `[* *]` | 媒体块 | 显示图片或视频 | 前端 |
| `[= =]` | 输入框 | 接收用户输入，可绑定变量名 | 前端 |
| `[( )]` | 按钮 | 纯按钮（配合路由跳转） | 前端 |
| `[> <]` | 行为按钮 | 点击后触发逻辑的按钮 | 前端 |
| `[/ /]` | 路由 | 页面路径声明或跳转目标 | 前端 |
| `[---]` | 分割线 | 上下内容之间画一条线 | 前端 |
| `[> >]` | 执行块 | 定义/执行一段逻辑 | 逻辑 |
| `[? ?]` | 分支块 | 条件判断，`[?? ??]` 为否则 | 逻辑 |
| `[~ ~]` | 循环块 | 重复执行 | 逻辑 |
| `[# #]` | 数据抽屉 | 声明变量 | 数据 |
| `[$ $]` | 计算器 | 算术与数值运算 | 数据 |
| `[+ 组件名 … +]` | 组件定义 | 定义可复用组件（v2.1 新增） | 复用 |
| `[< >]` | 组件调用 | 使用已定义组件（v2.1 新增） | 复用 |
| `[! !]` | 注释 | 不参与执行 | 通用 |
| `[!!]` | 行内分隔符 | **可选**。仅在一行写多条语句时使用（v2.1 降级） | 通用 |

### 2.2 预留符号（v2.1 降级：语义已占位、暂不实现）

| 符号 | 预留含义 | 状态 |
|------|----------|------|
| `[b d]` | 后端块（backend，服务器端逻辑） | 预留，勿用 |
| `[u n]` | 用户块（登录/身份/权限） | 预留，勿用 |
| `[q p]` | 查询块（数据库查询） | 预留，勿用 |
| `[@ @]` | 网络块（请求外部接口） | 预留，勿用 |

> **预留区规则**：解释器遇到预留符号时必须报错并提示「该符号在 v3.0 后开放」。规范文档不为其编写示例，避免使用者误以为后端已可用。

### 2.3 符号表冻结声明

**v2.1 的 17 对正式符号即最终符号集，不再新增括号对。** 之后所有能力扩展一律通过块内属性实现（如 `[+ 宽=600 居中 … +]`），不改符号表。

## 三、基础语法规则（v2.1 修订）

### 规则 1：一切皆嵌套

```
[+
  [- 外层文字 -]
  [+
    [- 内层文字 -]
  +]
+]
```

### 规则 2：换行即结束（v2.1 核心变更）

- **一行写一个语句**，换行即该语句结束，不需要任何收尾符号。
- 容器框（`[+ +]`、`[? ?]`、`[~ ~]` 等）靠右括号闭合，与换行无关。
- `[!!]` 仅作为**可选行内分隔符**：一行内写多条语句时才用。

```
[! v2.0 写法 —— 已废弃 !]
[- 你好 -] [!!]
[- 欢迎回来 -] [!!]

[! v2.1 写法 —— 换行即结束 !]
[- 你好 -]
[- 欢迎回来 -]

[! 行内分隔符：仅一行多句时使用 !]
[- 你好 -] [!!] [- 欢迎回来 -]
```

### 规则 3：注释

```
[! 这里是注释，不参与执行 !]
```

注释必须成对闭合，且不能嵌套注释。

### 规则 4：分割线

```
[---]
```

## 四、作用域规则（v2.1 新增）

### 4.1 词法块级作用域

- `[# 变量 = 值 #]` 声明的变量，**作用域为包含它的最内层容器**（从声明处到该容器闭合）。
- 内层块可以**读取**外层块的变量（词法作用域，逐层向外查找）。
- 内层块对同名变量**赋值**时，修改的是最近的外层声明；内层想新开一个同名变量，必须先用 `[#]` 声明。

```
[# 计数 = 0 #]
[+
  [$ 计数 = 计数 + 1 $]        [! 修改的是外层的 计数 !]
  [~
    [# 计数 = 99 #]            [! 声明后：循环内新开一个局部 计数 !]
    [$ 计数 = 计数 + 1 $]
  ~]
+]
```

### 4.2 组件作用域（v2.1 新增）

组件是**独立作用域**：组件体只能访问自己声明的变量和传入的属性，**不捕获**外部变量。与外界的唯一通道是属性传值。

```
[! 定义组件：欢迎卡 !]
[+ 组件 欢迎卡
  属性 名字, 等级
  [+
    [- 你好，{名字}！你的等级是 {等级} -]
  +]
+]

[! 调用组件：属性通过调用处传入 !]
[< 欢迎卡 名字="张三" 等级=3 >]
```

- `属性` 行声明组件的形式参数，多个用逗号分隔。
- 组件体内用 `{名字}` 插值引用属性值。
- 调用处传值：字符串用引号，数值/变量直接写。
- 组件定义可以被调用任意多次；定义必须出现在首次调用之前（同文件）或通过模块引入。

### 4.3 模块引用

```
[! 从别的文件引入组件 !]
引入 "./导航条.bd" 的 导航条, 页脚
```

被引入文件中被 `[+ 组件 … +]` 定义的组件即可在当前文件调用。

## 五、形式化文法（EBNF，v2.1 新增）

以下文法覆盖 v2.1 全部正式符号。约定：`::=` 定义，`|` 或，`{ }` 重复零次以上，`[ ]_ebnf` 可选，`LF` 换行，终端符号加引号。

```ebnf
(* ===== 顶层 ===== *)
program      = file-head , { item , LF } , file-tail ;
file-head    = "[" , "ese.bd" , LF ;
file-tail    = "]" ;
module-file  = "[" , identifier , ".bd" , LF , { item , LF } , "]" ;

(* ===== 条目 ===== *)
item         = container | statement | comment | divider | newline-gap ;

statement    = container ;
newline-gap  = (* 空行，忽略 *) ;

(* ===== 容器类（自带闭合，不依赖换行） ===== *)
container    = panel | text | media | input | button | action-button
             | route | branch | loop | data | calc
             | component-def | component-call | exec ;

panel        = "[" , "+" , attr* , LF , { item , LF } , "]" ;
text         = "[" , "-" , text-body , "-" , "]" ;
media        = "[" , "*" , filename , "*" , "]" ;
input        = "[" , "=" , identifier , "=" , "]" ;
button       = "(" , text-body , ")" , wrapped-in-brackets ;
action-button= "[" , ">" , text-body , "<" , "]" , [ invoke ] ;
route        = "[" , "/" , path , "/" , "]" ;
exec         = "[" , ">" , [ exec-name , ":" ] , LF , { item , LF } , "]" ;
invoke       = "调用" , exec-name ;

branch       = "[" , "?" , condition , LF , { item , LF } , else-part? , "]" ;
else-part    = "[" , "??" , LF , { item , LF } , "?]" ;
condition    = value , compare-op , value ;
compare-op   = "==" | "!=" | ">" | "<" | ">=" | "<=" ;

loop         = "[" , "~" , ( count | condition ) , LF , { item , LF } , "]" ;
count        = number , "次" | identifier , "次" ;

data         = "[" , "#" , identifier , "=" , value , "#" , "]" ;
calc         = "[" , "$" , identifier , "=" , calc-expr , "$" , "]" ;
calc-expr    = value , { arith-op , value } ;
arith-op     = "+" | "-" | "*" | "/" ;

(* ===== 组件（v2.1 新增） ===== *)
component-def= "[" , "+" , "组件" , identifier , LF , { attr-line | item , LF } , "]" ;
attr-line    = "属性" , identifier , { "," , identifier } ;
component-call = "[" , "<" , identifier , prop-pass* , ">" , "]" ;
prop-pass    = identifier , "=" , ( string | number | identifier ) ;

(* ===== 复用/杂项 ===== *)
comment      = "[" , "!" , { any-char } , "!" , "]" ;
divider      = "[" , "-" , "-" , "-" , "]" ;
inline-sep   = "[" , "!" , "!" , ] ;        (* 可选，仅一行多句时使用 *)
import       = "引入" , string , "的" , identifier , { "," , identifier } ;

(* ===== 词法 ===== *)
identifier   = letter , { letter | digit | "_" } ;   (* 中文字符视为 letter *)
string       = '"' , { any-char } , '"' ;
number       = digit , { digit } ;
value        = string | number | identifier | interpolation ;
interpolation= "{" , identifier , "}" ;
attr         = identifier , "=" , value , space ;
path         = "/" , { path-segment , "/" } ;
```

### 文法要点说明

1. **`statement = container`**：语句就是容器，闭合即结束——这正是「换行即结束」的形式化表达：`[!!]` 从文法主体中移除，只保留在 `inline-sep` 可选项中。
2. **`exec` 的两用**：`[> 名字: … >]` 定义命名逻辑块；无名执行块立即执行。行为按钮通过 `调用 名字` 引用（事件绑定采用命名触发器方案）。
3. **`branch` 的 `else-part?`**：`[?? ??]` 只能出现在 `[? ?]` 内部最后一个位置，消除嵌套歧义。
4. **预留符号不在文法中**：`[b d] [u n] [q p] [@ @]` 无法由此文法推导，解析器遇到即报错——这是「预留区」的强制保证。
5. **缩进与空格**：仅用于人类可读性，不参与语义。语义由括号配对 + 换行决定。

## 六、符号详解（正式符号）

### 6.1 前端层

```
[! 浮雕框：页面容器，支持属性 !]
[+ 宽=600 居中
  [- 欢迎来到我的网站 -]
+]

[! 文字与媒体 !]
[- 一段普通文字 -]
[* 头像.png *]

[! 输入框：绑定变量 !]
[# 名字 = "" #]
[= 名字 =]

[! 纯按钮 + 路由跳转 !]
[( 去首页 )] [/ /home /]

[! 行为按钮：点击后执行命名逻辑块 !]
[> 提交 :
  [- 提交中…… -]
>]
[> 登录 <] 调用 提交

[! 属性示例（代替新符号扩展样式） !]
[+ 宽=600 居中 背景="#f7f8fa"
  [- 属性驱动的排版，不再需要 [w m] -]
+]
```

> **变更说明**：v2.0 的 `[w m]` 排版块已并入容器属性（`宽=`、`居中` 等），符号表相应减一。这也兑现了「属性代替新符号」的冻结策略。

### 6.2 逻辑层

```
[! 分支 + 否则 !]
[? 名字 == "张三"
  [- 欢迎老板！ -]
  [??
    [- 你是谁？ -]
  ??]
?]

[! 循环：次数或条件 !]
[~ 3次
  [- 循环中 -]
~]
```

### 6.3 数据层

```
[# 名字 = "张三" #]
[# 计数 = 0 #]
[$ 计数 = 计数 + 1 $]
[$ 总价 = 单价 * 数量 $]
```

### 6.4 组件（v2.1 新增）

```
[! ① 定义 !]
[+ 组件 欢迎卡
  属性 名字, 等级
  [+ 居中
    [- 你好，{名字}！等级 {等级} -]
  +]
+]

[! ② 复用：定义一次，调用任意次 !]
[< 欢迎卡 名字="张三" 等级=3 >]
[< 欢迎卡 名字="李四" 等级=7 >]

[! ③ 跨文件复用 !]
引入 "./欢迎卡.bd" 的 欢迎卡
```

### 6.5 预留区（不可使用）

```
[! 以下写法在 v2.1 下会直接报错 !]
[b 服务器逻辑 d]      [! ✗ 报错：v3.0 后开放 !]
[u 登录 名字, 密码 n]  [! ✗ 报错：v3.0 后开放 !]
[q 取出 用户 p]        [! ✗ 报错：v3.0 后开放 !]
[@ 获取用户数据 @]     [! ✗ 报错：v3.0 后开放 !]
```

## 七、完整示例：欢迎页（v2.1 风格）

```
[ese.bd
  [! 变量 !]
  [# 名字 = "" #]

  [! 组件：欢迎卡 !]
  [+ 组件 欢迎卡
    属性 名字
    [+ 居中
      [- 你好，{名字}！欢迎来到 ese 的世界！ -]
    +]
  +]

  [! 页面主体 !]
  [+ 宽=600 居中
    [- 请输入你的名字 -]
    [= 名字 =]
    [> 登录 <] 调用 打招呼
    [---]
    [< 欢迎卡 名字="游客" >]
  +]

  [! 命名逻辑块 !]
  [> 打招呼 :
    [? 名字 == ""
      [- 名字不能为空！ -]
      [??
        [< 欢迎卡 名字=名字 >]
      ??]
    ?]
  >]
]
```

注意对比：与 v2.0 相比，本示例**没有任何一行 `[!!]`**，行数减少约三分之一，且按钮与逻辑通过「命名触发器」显式连接。
